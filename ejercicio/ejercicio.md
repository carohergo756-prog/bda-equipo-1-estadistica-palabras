# Ejercicio - Ciberseguridad

## Objetivo
Utilizar WordMean y WordMedian de Hadoop para analizar la longitud de las palabras de un texto.

## Texto de entrada

La seguridad digital ayuda a proteger los datos personales
Usar claves seguras evita riesgos en internet
Los usuarios deben cuidar su informacion

## Instrucciones

1. Utiliza el archivo `datos/ciberseguridad.txt` del repositorio.
2. Copia el archivo al contenedor siguiendo las instrucciones del README.
3. Ejecuta WordMean y WordMedian.
4. Consulta los resultados de ambos programas.
5. Responde las siguientes preguntas.

## Preguntas

1. ¿Cuántas palabras se analizaron?
2. ¿Cuál fue la longitud promedio de las palabras?
3. ¿Cuál fue la mediana obtenida?
4. ¿Qué diferencia existe entre los resultados de WordMean y WordMedian?
